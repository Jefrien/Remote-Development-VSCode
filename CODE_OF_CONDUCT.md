# Code of Conduct

We want this project to be welcoming and constructive for everyone.

Participants are expected to:

- be respectful and assume good intent;
- provide actionable, technical feedback;
- welcome different backgrounds and approaches;
- keep discussions focused on the project.

Harassment, discrimination, personal attacks, doxxing, and disruptive conduct
are not acceptable. Report concerns privately to the maintainer through the
security contact described in `SECURITY.md`.
